# AR6_NetZero
A small, reproducible Python example that works with the public [IPCC AR6 Scenario Database](https://data.ece.iiasa.ac.at/ar6/) (hosted by IIASA).  For every scenario in the 1.5°C and 2°C categories (C1, C2, C3) it finds the year in which global net CO2 emissions first reach zero, summarises the timing per category and draws two figures.
