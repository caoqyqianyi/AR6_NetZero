# When does net-zero CO₂ happen in IPCC AR6 scenarios?

[![Python](https://img.shields.io/badge/python-3.11%2B-blue.svg)](https://www.python.org/downloads/)
[![Data: IPCC AR6](https://img.shields.io/badge/data-IPCC%20AR6%20Scenario%20Database-0072B2.svg)](https://data.ece.iiasa.ac.at/ar6/)
[![Reproducible](https://img.shields.io/badge/reproducible-single%20script-009E73.svg)](#quick-start)

A small, fully reproducible Python analysis of the public
[IPCC AR6 Scenario Database](https://data.ece.iiasa.ac.at/ar6/) (hosted by IIASA).
For every scenario in the 1.5 °C and 2 °C temperature categories (**C1–C3**), the script
estimates the year in which **global net CO₂ emissions first reach zero**, summarises the
timing per category, and writes two figures and two CSV tables.

The project started as a first look at how integrated assessment scenarios are structured,
motivated by the question of **residual emissions** in deep-mitigation pathways. It is
deliberately kept to a single, dependency-light script so that every step is easy to read,
run, and test.

## Key findings

Results from the latest run against the live `ar6-public` database.
Numbers are regenerated by the script and may shift slightly with database releases.

| Category | Scenarios | Reaching net zero by 2100 | Median net-zero year | Interquartile range (P25–P75) |
|----------|----------:|--------------------------:|---------------------:|-------------------------------|
| **C1** – 1.5 °C, no/limited overshoot| 97  | 94  | **2054.1** | 2048.8 – 2060.4 |
| **C2** – 1.5 °C, high overshoot| 133 | 133 | **2059.3** | 2053.1 – 2063.1 |
| **C3** – 2 °C, likely| 306 | 259 | **2071.2** | 2066.9 – 2079.0 |

Tighter temperature goals go hand in hand with earlier net-zero CO₂, and the median
C1 pathway reaches net zero roughly 17 years before the median C3 pathway. Scenarios that
never cross zero by 2100 (3 in C1, 47 in C3) are counted but excluded from the timing
statistics.

## Temperature categories

Categories are assigned by the AR6 database based on projected warming outcomes and are
taken from the `Category` meta indicator (see IPCC AR6 WGIII Annex III).

| Category | Meaning |
|----------|---------|
| **C1** | Limit warming to 1.5 °C (>50 % chance) with no or limited overshoot |
| **C2** | Return warming to 1.5 °C (>50 %) after a high overshoot |
| **C3** | Limit warming to 2 °C (>67 % chance) |

## Quick start

**Prerequisites:** Python 3.11+ and internet access for the live database query.

```bash
# 1. (Recommended) create a virtual environment
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the analysis
python ar6_netzero.py            # downloads the public AR6 data and writes outputs/
python ar6_netzero.py --demo     # synthetic data, no internet needed
```

An offline `--demo` mode generates synthetic pathways in the same data format so the
pipeline can be explored without installing `pyam` or contacting IIASA. Demo figures are
watermarked **"SYNTHETIC DEMO DATA, NOT AR6 RESULTS"** and demo files are written with a
`demo_` prefix.

## Usage

```text
python ar6_netzero.py [--demo] [--out OUTPUT_DIR]
```

| Option | Description | Default |
|--------|-------------|---------|
| `--demo` | Use synthetic data instead of downloading the AR6 database | off (live data) |
| `--out`  | Directory for generated figures and tables | `outputs/` |

```bash
python ar6_netzero.py --out results/      # write outputs somewhere else
```

## Outputs

All files are written to `outputs/` (or the folder given by `--out`).

| File | Content |
|------|---------|
| `net_co2_pathways.png` | Net CO₂ pathways: thin line per scenario, thick line the median per category |
| `net_zero_timing.png`  | Boxplot of net-zero years per category |
| `net_zero_years.csv`   | Net-zero year for every individual scenario (blank if never reached) |
| `summary.csv`          | Scenario counts, number reaching net zero, and median/quartiles per category |

Committed copies of the two figures from the latest live run are kept in [`figures/`](figures)
so they render in this README before the script is run.

## Method

1. **Data query.** Global net CO₂ emissions are loaded with
   `pyam.read_iiasa("ar6-public", variable="Emissions|CO2", region="World", meta=True)`,
   along with each scenario's `Category` meta indicator. No login is required for the
   public database.
2. **Category filtering.** Full category labels (e.g. `C1: limit warming to 1.5C …`) are
   reduced to their `C1`/`C2`/`C3` prefixes; only these three categories are retained.
3. **Unit conversion.** Emissions are converted from Mt CO₂/yr to Gt CO₂/yr.
4. **Net-zero crossing.** For each scenario, time steps are sorted and the first value at or
   below zero is located. The crossing year is obtained by **linear interpolation** between
   the last positive step and the first non-positive step:

   $$t_{nz} = t_0 + (t_1 - t_0)\,\frac{E_0}{E_0 - E_1}, \qquad E_0 > 0 \ge E_1$$

   If a series is already non-positive at the first time step, that year is returned; if it
   never reaches zero, the result is `NaN` and the scenario is counted but left out of the
   timing statistics.
5. **Summary.** For each category the script reports the number of scenarios, how many reach
   net zero, and the median, 25th and 75th percentile crossing years. Every scenario is
   weighted equally.

The analysis covers **net CO₂ only** (`Emissions|CO2`). Gross emissions and residual
emissions cannot be derived from this single reporting variable.

## Tests

The analysis logic is covered by 9 unit tests that run entirely on synthetic data, so they
need no internet connection:

```bash
python -m unittest -v
```

The tests cover the interpolation formula (mid-point, proportional, exact zero),
unsorted time steps, series that never reach zero or start already below zero,
category filtering and unit conversion, the summary statistics, and an end-to-end demo run.

## Reproducibility notes

- The live query hits the public IIASA Scenario Explorer; output therefore depends on the
  current `ar6-public` release and on IIASA being reachable. The figures above were
  generated on 23 October 2026 with Python 3.14, `pyam-iamc` 4.0, pandas 3.0 and
  matplotlib 3.10.
- `requirements.txt` is unpinned; use `pip freeze` if you need an exact frozen environment.
- Re-running the script overwrites the files in the output directory; it never modifies the
  source data.

## Limitations

- **Net CO₂ only.** Gross emissions, carbon dioxide removal and residual emissions are not
  analysed.
- **Interpolation.** Linear interpolation between model time steps (commonly 5 or 10 years)
  is a simplification; the true pathway within a model step need not be linear.
- **Equal weighting.** Scenarios from different models and model families are treated as
  independent, equally weighted points. High-output modelling groups therefore contribute
  more scenarios, and no reweighting or de-duplication by scenario family is performed.
- Categories reflect the database's own warming classification; no climate emulation is
  re-run here.

## Possible next steps

- Add categories C4–C8 and compare the computed years with the database's
  `Year of netzero CO2 emissions` meta indicator.
- Examine carbon dioxide removal variables (e.g. `Carbon Sequestration|…`) and what they
  imply for residual emissions.
- Break results down by model family and by shared socio-economic pathway (SSP).
- Add confidence intervals or a model-family-balanced summary.

## Data sources and citation

The data is the **AR6 Scenarios Database**, compiled for Working Group III of the IPCC and
hosted by IIASA. When re-using the data, follow the database's recommended citation:

> Byers, E., Krey, V., Kriegler, E., Riahi, K., Schaeffer, R., Kikstra, J., et al. (2022).
> *AR6 Scenarios Database hosted by IIASA*. International Institute for Applied Systems
> Analysis. <https://doi.org/10.5281/zenodo.5886911>

For global mitigation pathways, also consider citing IPCC AR6 WGIII Chapter 3:
Riahi, K., Schaeffer, R., et al. (2022), *Mitigation Pathways Compatible with Long-Term
Goals*, in **Climate Change 2022: Mitigation of Climate Change**, IPCC, Geneva.

Data access uses the [pyam](https://pyam-iamc.readthedocs.io/) Python package.
